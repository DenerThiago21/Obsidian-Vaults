Sim. Para aprender **Java + lógica + algoritmos + estruturas de dados + banco de dados + Spring Boot** sem pagar, recomendo montar uma trilha com vários cursos gratuitos. Um único curso raramente cobre todos esses assuntos com profundidade.

## Trilha gratuita recomendada

### 1. Lógica e Java básico

Comece pelo curso **Java Básico – Curso em Vídeo**, que cobre instalação do JDK, sintaxe, variáveis, condicionais, repetições, vetores, métodos e os primeiros conceitos de Java. O curso tem aproximadamente 40 horas e as aulas são gratuitas. [cursoemvideo](https://www.cursoemvideo.com/curso/java-basico/)

Estude nesta ordem:

- Variáveis e tipos de dados.
- Operadores e expressões.
- `if`, `else` e `switch`.
- Laços `for`, `while` e `do while`.
- Métodos.
- Arrays e matrizes.
- Strings.
- Classes e objetos.
- Encapsulamento.
- Herança, polimorfismo e interfaces.
- Exceções e organização de pacotes.

**Exercícios recomendados:** calculadora, conversor de temperatura, sistema de notas, caixa eletrônico, cadastro de produtos e agenda de contatos.

### 2. Algoritmos e estruturas de dados

Depois, faça o curso gratuito de **Estrutura de Dados e Algoritmos com Java**, da Loiane Groner. Ele possui aulas, código-fonte e material de apoio, abordando vetores, listas, pilhas, filas, árvores, tabelas hash, grafos e algoritmos de ordenação. [youtube](https://www.youtube.com/watch?v=N3K8PjFOhy4)

Também é útil acompanhar um curso mais direto sobre:

- Notação Big O.
- Busca linear e binária.
- Bubble Sort, Selection Sort e Insertion Sort.
- Merge Sort e Quick Sort.
- `ArrayList`, `LinkedList`, `Stack`, `Queue`, `HashMap` e `HashSet`.
- Árvores binárias.
- Heaps.
- Grafos e algoritmo de Dijkstra.

Não apenas assista às aulas: implemente cada estrutura manualmente e depois compare com as coleções prontas do Java.

### 3. Banco de dados e SQL

Para a parte de banco de dados, estude:

- Modelo relacional.
- Tabelas, chaves primárias e estrangeiras.
- `SELECT`, `INSERT`, `UPDATE` e `DELETE`.
- `JOIN`.
- Agrupamentos com `GROUP BY`.
- Subconsultas.
- Índices.
- Normalização.
- Transações.
- Modelagem usando DER.

O curso gratuito de SQL da **FGV** tem 24 horas e é uma boa introdução para consultas e manipulação de dados.  Como prática interativa, o Coddy permite executar consultas SQL diretamente no navegador, sem instalar um banco local. [educacao-executiva.fgv](https://educacao-executiva.fgv.br/cursos/online/curta-media-duracao-online/sql-structured-query-language)

Depois instale PostgreSQL ou MySQL e pratique localmente. Para Spring Boot, eu escolheria **PostgreSQL**, porque ele é gratuito, robusto e muito usado em aplicações profissionais.

### 4. Java moderno e desenvolvimento web

Antes de Spring Boot, aprenda:

- Generics.
- Interfaces funcionais.
- Expressões lambda.
- Streams.
- `Optional`.
- Coleções.
- Maven.
- JUnit.
- Git e GitHub.
- JSON.
- HTTP e APIs REST.

Essa etapa evita que você aprenda Spring apenas “copiando anotações” sem entender o Java por trás.

### 5. Spring Boot

O curso gratuito da **Rocketseat – Java com Spring Boot** constrói uma API de tarefas do zero. Ele aborda rotas HTTP, integração com banco de dados, autenticação JWT, Spring Security e deploy. [app.rocketseat.com](https://app.rocketseat.com.br/jornada/java-com-spring-boot-curso-introdutorio/visao-geral)

Como complemento, o minicurso de Spring Boot da **Matheus Leandro Ferreira** aborda:

- Spring Initializr.
- Maven e `pom.xml`.
- `@RestController`.
- Rotas REST.
- Injeção de dependências.
- Tratamento de exceções.
- Spring Data JPA.
- PostgreSQL.
- Logs.
- Operações `GET`, `POST`, `PUT` e `DELETE`.

O conteúdo inclui a criação de uma API com persistência em banco de dados e testes dos endpoints. [youtube](https://www.youtube.com/watch?v=SqU9v_V32RA)

### 6. JPA, segurança e projeto final

Depois dos fundamentos, aprofunde-se em:

- Entidades com `@Entity`.
- Relacionamentos `@OneToMany`, `@ManyToOne` e `@ManyToMany`.
- Repositórios.
- DTOs.
- Validação com Bean Validation.
- Paginação.
- Tratamento global de erros.
- JWT.
- Perfis de usuário.
- Testes com JUnit e Mockito.
- Docker.
- Documentação com Swagger/OpenAPI.

O curso gratuito de Spring Data JPA da Decoder é interessante para estudar mapeamentos e relacionamentos entre entidades. [decoder](https://www.decoder.dev/cursos-gratuitos)

## Projeto recomendado

Construa uma **API de inventário de equipamentos de TI**, aproveitando sua experiência com infraestrutura:

- Cadastro de equipamentos.
- Usuários e setores.
- Localização de cada equipamento.
- Histórico de manutenção.
- Controle de empréstimos.
- Autenticação com JWT.
- PostgreSQL.
- Documentação Swagger.
- Testes automatizados.
- Docker Compose com a aplicação e o banco.
- Deploy em um servidor Linux ou VPS.

Esse projeto demonstraria Java, Spring Boot, banco de dados, REST, autenticação, testes, Docker e administração Linux em um único portfólio.

## Ordem e duração

Uma sequência realista seria:

| Etapa | Tempo aproximado |
|---|---:|
| Java e lógica | 6–8 semanas |
| POO e Java moderno | 4–6 semanas |
| Algoritmos e estruturas de dados | 6–8 semanas |
| SQL e PostgreSQL | 3–4 semanas |
| APIs REST e Spring Boot | 6–8 semanas |
| Projeto final e testes | 4–6 semanas |

Estudando de 1 a 2 horas por dia, essa trilha pode levar aproximadamente **6 a 9 meses**. Como você já tem experiência com Linux, servidores e automação, provavelmente poderá avançar mais rapidamente na parte de ambiente, Git, terminal e Docker.
